# CV Generator - Quick Reference

This directory contains the CV files for the portfolio website.

## Files

- `[Your_Name]_CV.html` - The HTML version of the CV
- `[Your_Name]_CV.pdf` - The PDF version of the CV (generated from the HTML)

## Quick Generation

```bash
npm run generate-cv
```

## Features

- **Professional Design**: Matches the portfolio website's theme and color scheme
- **ATS-Friendly**: Structured with clear sections and keywords for Applicant Tracking Systems
- **Print-Optimized**: Proper margins and page breaks for professional appearance
- **Website Integration**: Available for download directly from the portfolio website

## Full Documentation

For complete setup instructions, customization options, and troubleshooting, see the [CV Generator Documentation](../CV_GENERATOR.md) in the project root.

## Color Scheme

The CV uses the same color scheme as the portfolio website:

- Primary color (background): #0a192f (dark blue)
- Secondary color (accents): #37e784 (green)
- Text color: #ccd6f6 (light blue/gray)
- Content color: #8892b0 (lighter gray)
